## 5. 追踪和变更规则

1. 新 PRD 需求必须先获得 REQ-* 编号，再添加到本文件和计划中的 Task。
2. 需求变更必须同时更新优先级、MVP/P1/排除项归属、验收证据和前置依赖。
3. 任一 Task 完成时，必须补充真实命令、测试或页面证据；静态表格不等同于功能完成。
4. 若需求从 P1 升为 P0，必须重新评审数据库、中间件、权限、审计、性能和回滚影响。
